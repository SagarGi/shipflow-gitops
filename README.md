# ShipFlow GitOps

A production-style DevOps portfolio project demonstrating a complete GitOps workflow using:

- Node.js
- Docker
- Kubernetes
- Helm
- Argo CD
- GitHub Actions

## Project Status

🚧 Under Development

## Goals

- Build a containerized microservice
- Package it using Helm
- Deploy using Argo CD
- Automate CI/CD using GitHub Actions
